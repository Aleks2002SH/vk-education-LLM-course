# vk-education-LLM-course
This repository contains my completed homework assignments for the Large Language Models course from VK education.

The goal of the course is to explore the inner workings of large language models (LLMs) and to learn about effective methods for their training and optimization.

## Course Overview

During this course, we studied the architecture, training, and fine-tuning of modern LLMs, including models from the BERT and GPT families. The program also covered model optimization, inference acceleration, and recent approaches to alignment, parameter-efficient fine-tuning, and retrieval-augmented generation (RAG).
## Homeworks

### Homework 1 — BPE and Vanilla Transformer
Topics:  
- Implementation of Byte Pair Encoding (BPE) tokenizer  
- Implementation of vanilla Transformer model  
- Integration of RoPE (Rotary Position Embedding)  
- Implementation of Multi-Head Linear Attention (MHLA) 
- Repository documentation and HF model upload  
Result: Fully functional Transformer generating coherent text; models uploaded to Hugging Face Hub.

### Homework 2 — DPO and PPO Training
Topics:  
- Data preparation for *Direct Preference Optimization (DPO)   
- Reward model and PPO fine-tuning 
- Model analysis and reporting  
- Hugging Face card with results  

Result: Successfully implemented and fine-tuned PPO-based model, with full evaluation and HF upload.

### Homework 3 — Parameter-Efficient Fine-Tuning (PEFT)
Topics: 
- Dataset preparation and postprocessing  
- LoRA adaptation and training  
- DoRA fine-tuning  
- Bonus: QLoRA and framework-based PEFT implementation  
- Hugging Face repository with documentation  

Result: Functional LoRA/DoRA fine-tuned models demonstrating reduced compute requirements.

###  Homework 4 — Retrieval-Augmented Generation (RAG)
Topics: 
- Embedding evaluation and alignment scoring  
- Vector search and retrieval setup  
- Prompt engineering (with and without RAG)  
- BLEU-based and LLM-as-judge evaluation  
- Bonus: embedding quality analysis and scoring automation  

Result: Working RAG pipeline with embedding quality experiments and automated evaluation.

Developed as part of the vk education Large Language Models course.
